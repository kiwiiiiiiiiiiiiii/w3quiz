# PRINCIPAL EXAM 2026 — राधाकृष्णन आयोग MCQ टेस्ट

प्रधानाचार्य परीक्षा 2026 के लिए **राधाकृष्णन आयोग (1948–49) / विश्वविद्यालय शिक्षा आयोग** पर आधारित 50 प्रश्नों का अभ्यास टेस्ट।

## विशेषताएँ

- ✅ 50 बहुविकल्पीय प्रश्न (हिन्दी में)
- ✅ एक समय में एक प्रश्न, आगे-पीछे नेविगेशन
- ✅ प्रश्न सूची (Question Map) से सीधे किसी भी प्रश्न पर जाएँ
- ✅ परीक्षा परिणाम — स्कोर, प्रतिशत, सही/गलत/अनुत्तरित
- ✅ सभी प्रश्नों की विस्तृत समीक्षा और व्याख्या
- ✅ मोबाइल, टैबलेट और डेस्कटॉप पर उत्तरदायी (Responsive)
- ✅ कोई बैकएंड, API या डेटाबेस नहीं — पूरी तरह स्टैटिक

## फाइल संरचना


## GitHub पर अपलोड करें

1. GitHub पर एक नया repository बनाएँ
2. इस फोल्डर की सभी फाइलें अपलोड करें:
   ```bash
   git init
   git add .
   git commit -m "Principal Exam 2026 - Radhakrishnan Commission Quiz"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```

## Vercel पर Deploy करें

1. [vercel.com](https://vercel.com) पर जाएँ और अपने GitHub अकाउंट से लॉगिन करें
2. "Add New" → "Project" पर क्लिक करें
3. अपना repository सेलेक्ट करें
4. Framework Preset: **Other** चुनें
5. "Deploy" पर क्लिक करें
6. कुछ ही सेकंड में आपकी साइट लाइव हो जाएगी! 🎉
